# Руководство по использованию v2rayA и проксированию

Данное руководство составлено для пользователей скрипта установки `8_v2raya-proxy.sh`. Оно описывает базовые принципы работы с v2rayA, сброс пароля и настройку глобального проксирования (TUN Mode) в Linux.

## 1. Первый запуск и пароль
У v2rayA **нет пароля по умолчанию**. 
При первом открытии веб-интерфейса (доступен по адресу `http://127.0.0.1:2017`) система предложит вам самостоятельно придумать и ввести логин и пароль администратора. В дальнейшем эти данные будут использоваться для входа.

## 2. Сброс забытого пароля
Если вы забыли пароль от веб-интерфейса, его можно сбросить через терминал. 

**Внимание:** Для успешного сброса пароля необходимо сначала остановить системную службу v2rayA, иначе она заблокирует базу данных.

Для сброса выполните следующую цепочку команд:
```bash
sudo systemctl stop v2raya
sudo v2raya --reset-password
sudo systemctl start v2raya
```
После выполнения этих команд **обязательно жестко обновите страницу в браузере (Ctrl+F5)** или откройте веб-интерфейс в режиме инкогнито. Это необходимо, так как браузер может закэшировать старый недействительный токен авторизации (что вызывает ошибки `401 Unauthorized` и пустой экран).

## 3. Два режима работы: proxy-switch vs TUN Mode

В системе предусмотрено два принципиально разных способа направить трафик через прокси.

### Способ А: Локальный прокси для терминала (`proxy-switch`)
Утилита `proxy-switch` (устанавливается вместе со скриптом) переводит в режим прокси **только текущий терминал** и те утилиты командной строки, которые вы запустите непосредственно из него (например, `curl`, `git`, `apt`).
Всю остальную операционную систему (графические браузеры, Telegram, системные службы) эта команда **не затрагивает**.

- Включить: `proxy-switch on` (и выполнить команду применения переменных, например `source ~/.proxy-env`)
- Выключить: `proxy-switch off`
- Статус: `proxy-switch status`

### Способ Б: Прозрачное проксирование всей системы (TUN Mode)
Это режим полноценного VPN. v2rayA создает виртуальный сетевой интерфейс (туннель) и перехватывает трафик **всей операционной системы** на уровне ядра Linux. Ни в браузере, ни в других приложениях настраивать прокси больше не нужно — всё работает автоматически.

**Как включить TUN Mode:**
1. Откройте веб-интерфейс `http://127.0.0.1:2017`
2. Перейдите в **Settings** (Настройки) в правом верхнем углу.
3. В разделе **Transparent Proxy** выберите **system proxy**.
4. В разделе реализации выберите **TUN**.
5. Выберите правило маршрутизации (см. ниже) и сохраните.

> **⚠️ ВАЖНО:** Никогда не используйте команду `proxy-switch on` при включенном режиме TUN! Это приведет к петле маршрутизации (routing loop) — трафик закольцуется и интернет на компьютере пропадет.

## 4. Настройка правил маршрутизации (Routing Rules)

В настройках прозрачного проксирования вам будет предложено выбрать, какой именно трафик отправлять через прокси-сервер. Варианты в меню:

- **`On: Do not Split Traffic`** — Проксировать абсолютно весь системный трафик Linux. **Рекомендуемый вариант**, если вы хотите использовать v2rayA как VPN.
- **`On: Proxy except CN Sites`** — Проксировать всё, кроме ресурсов материкового Китая (для пользователей вне Китая работает аналогично "Do not Split Traffic").
- **`On: Proxy only GFWList`** — Умный режим: проксировать *только заблокированные сайты*. Удобно, если вам нужен доступ к санкционным ресурсам (например, Google Gemini, OpenAI), но вы не хотите пускать локальный трафик (банки, Госуслуги, местные сервисы) через удаленный сервер.
- **`Off`** — Прозрачное проксирование полностью выключено.
